## சிறப்பம்சங்கள் / Key Features
1. **இருமொழி வசதி (Bilingual Tamil & English):**
   - இயல்பாகவே முழு கணினியும் தமிழில் இயங்கும் (Default in Tamil).
   - திரையின் மேல் பகுதியில் உள்ள **"🌐 தமிழ் / English"** பொத்தானை அழுத்துவதன் மூலம் உடனடியாக தமிழுக்கும் ஆங்கிலத்திற்கும் மாற்றிக் கொள்ளலாம்.
2. **முன் ஏற்றுமதி செய்யப்பட்ட சரக்கு இருப்புப் பொருட்கள் (Pre-seeded Inventory Items):**
   - வெற்றிலை (Betel leaf)
   - புகையிலை (Tobacco)
   - சிகரெட் (Cigarettes)
   - பீடி (Beedi)
   - பூவாக் (Buwak)
   - சோடா (Soda)
   - பெப்சி (Pepsi)
   - கோகோ கோலா (Coca-cola)
   - ஸ்ப்ரைட் (Sprite)
   - மிரிண்டா (Mirinda)
   - பால் (Milk)
   - ஜூஸ் வகைகள் (Juice items)
   - பழங்கள் (Fruit)
   - காய்கறிகள் (Vegetable)
   - இனிப்பு வகைகள் (Sweet items)
   - பிஸ்கட் (Biscuits)
   - தண்ணீர் போத்தல் (Water bottle)
3. **பில்லிங் மற்றும் ரசீது (Billing & 80mm Thermal Receipt):**
   - தமிழ் மற்றும் ஆங்கிலத்தில் 80mm ரசீது அச்சிடுதல், வாட்ஸ்அப் மற்றும் எஸ்எம்எஸ் பகிர்வு.
4. **சரக்கு இருப்பு மேலாண்மை (Inventory Management):**
   - இருப்பு கண்காணிப்பு, குறைந்த இருப்பு எச்சரிக்கை, விலை திருத்தம், PDF அறிக்கை.
5. **வாடிக்கையாளர் மற்றும் வசூல் கணக்கு (Customers & Collections):**
   - கடன் மற்றும் நிலுவைத் தொகை கண்காணிப்பு, வரைபட இருப்பிடம்.
6. **செலவுகள் மற்றும் அறிக்கைகள் (Expenses & Reports):**
   - தினசரி விற்பனை, நிகர லாபம், நாள் முடிவு சுருக்கம் (Day Close).

## தொடங்குவது எப்படி / How to Start
1. உலாவியில் திறக்க: `index.html` கோப்பைத் திறக்கவும்.
2. சர்வரைத் தொடங்க: `start-mageshvani-server.bat` அல்லது `npm start` இயக்கவும்.
3. வெப் பதிப்பை உருவாக்க: `npm run build:web`
